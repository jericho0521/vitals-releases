# Notebook releases

Download the latest Notebook installers from the [Releases page](https://github.com/jericho0521/vitals-releases/releases).

- macOS: download the `.dmg` (Apple Silicon `aarch64` or Intel `x64`), open it, drag Notebook to Applications. On first launch, right-click the app and choose Open.
- Windows: download and run the `.exe` installer.
